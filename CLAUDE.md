# Regras do projeto

## Interface

- Botões sempre minimalistas: só texto curto, sem emojis. Isso vale para qualquer botão, aba, link com estilo de botão ou rótulo clicável, inclusive em templates gerados pelo `app.js`.
- Quando um controle precisar de ícone (ex.: favoritar), usar um glifo simples e monocromático (ex.: `★`/`☆`, `×`), nunca um emoji colorido.
